# Заготовка: двойственность — краткие ответы к упражнениям

Краткие ответы к упражнениям раздела 14 заготовки [`duality.md`](duality.md). Подробный разбор с кодом был в `exercises03.ipynb` лекции 3 до перестройки (история git, коммит с двойственностью); при переносе в лекции 10–11 собрать заново.

## 14.1. Одномерная задача

$h(x)=x-2\ge0$, $L(x,\mu)=x^2-\mu(x-2)$. Минимум по $x$: $x(\mu)=\mu/2$, откуда $d(\mu)=-\mu^2/4+2\mu$. Значения $d(0)=0$, $d(2)=3$, $d(4)=4$ — все $\le p^\ast=f(2)=4$. Максимум $d$ достигается при $\mu^\ast=4$: $d(4)=4=p^\ast$ — сильная двойственность (задача выпукла, Слейтер выполнен).

## 14.2. LP: где ломается теневая цена

Пока активны ограничения 2 и 3, движение по ребру $x_2=6$, $x_1=(b_3-12)/3$ продолжается до $b_3=24$, где $x_1$ упирается в своё ограничение $x_1\le4$. При $b_3\le24$ теневые цены — прежние $(0,\,1.5,\,1)$; при $b_3>24$ активны ограничения 1 и 2, а теневая цена третьего обязана обнулиться (комплементарная нежёсткость: неактивно $\Rightarrow$ множитель ноль), новые цены — из системы $A^\top y=c$ на активных строках: $y=(3,\,2.5,\,0)$.

## 14.3. QP с двумя активными ограничениями

$Q=\begin{pmatrix}1&0.8\\0.8&2\end{pmatrix}\succ0$ (собственные числа $\approx0.56,\,2.44$), решение $x^\ast=(-1,1)$ — активны сразу оба ограничения $x_1\ge-1$ и $x_2\le1$. Максимизация $d(\mu)$ даёт $\mu^\ast\approx(0,\,0.8,\,0.8,\,0)$, $d^\ast=f^\ast=-2.3$; комплементарная нежёсткость выполняется покоординатно для каждого из четырёх ограничений независимо. Баланс сил (раздел 5.1): $\nabla f(x^\ast)=Qx^\ast+c=(0.8,\,-0.8)$, а $\mu_2^\ast\nabla h_2+\mu_3^\ast\nabla h_3=0.8\cdot(1,0)+0.8\cdot(0,-1)=(0.8,\,-0.8)$ — совпадает; в сумму входят только нормали двух активных ограничений ($x_1\ge-1$ и $x_2\le1$), остальные два веса нулевые.

## 14.4. Слейтер для аффинных ограничений

Условие Слейтера требует строгой допустимости только для **нелинейных** $h_i$; для аффинных достаточно обычной $\ge0$. В LP все ограничения аффинны, поэтому условие не накладывает ничего сверх непустоты допустимого множества. Отсюда факт: **для любой разрешимой LP зазора двойственности нет никогда**, проверять условие Слейтера отдельно не нужно.

## 14.5. Скрытая выпуклость

При неактивных $x_1,x_2\ge0$ Лагранжиан $L(x,\lambda)=-4x_1x_2-\lambda(x_1^2+x_2^2-1)=-x^\top\begin{pmatrix}\lambda&2\\2&\lambda\end{pmatrix}x+\lambda$. Инфимум по $x\in\mathbb{R}^2$ конечен тогда и только тогда, когда $\begin{pmatrix}\lambda&2\\2&\lambda\end{pmatrix}\succeq0$, то есть $\lambda\ge2$ (собственные числа $\lambda\pm2$); тогда $d(\lambda)=-\lambda$, максимум при $\lambda^\ast=2$ даёт $d^\ast=-2=p^\ast$ — зазора нет, несмотря на нелинейное (невыпуклое) равенство. Отличие от примера раздела 6 конспекта (там зазор бесконечен): здесь только **одно** квадратичное ограничение — частный случай, где двойственность всегда точна (S-лемма), а не общее свойство невыпуклых задач.

## Вопросы для самопроверки

**1.** $L(x,\lambda,\mu)\le f(x)$ на допустимых $x$ при $\mu\ge0$, потому что $-\lambda^\top g(x)=0$ (равенство), а $-\mu^\top h(x)\le0$ (неотрицательное $\mu$ умножить на неотрицательное $h$ и вычесть). Отсюда $d(\lambda,\mu)=\inf_x L\le L(\bar x,\lambda,\mu)\le f(\bar x)$ для любой допустимой $\bar x$ — это и есть слабая двойственность.

**2.** $d(\lambda,\mu)=\inf_x L(x,\lambda,\mu)$ — поточечный инфимум функций, **линейных** по $(\lambda,\mu)$ при каждом фиксированном $x$; инфимум (в общем случае — семейства аффинных функций) всегда вогнут, независимо от того, выпукла ли $f$ по $x$.

**3.** Условие Слейтера: существует $\tilde x$ с $g(\tilde x)=0$ и $h_i(\tilde x)>0$ для всех **нелинейных** $h_i$ (для аффинных $h_i$ достаточно $\ge0$). Для чисто линейных ограничений условие вырождается в «допустимое множество непусто» — строгость нигде не требуется, поэтому оно выполняется автоматически.

**4.** Комплементарная нежёсткость: $\mu_i^\ast h_i(x^\ast)=0$ для каждого $i$ — следствие того, что при $d^\ast=p^\ast$ цепочка неравенств в доказательстве слабой двойственности превращается в цепочку равенств. Проверка на числах: посчитать $h_i(x^\ast)$ и $\mu_i^\ast$ по отдельности и убедиться, что хотя бы один из двух — ноль для каждого $i$.

**5.** $y_i^\ast$ — это в точности $df^\ast(b)/db_i$ в точке текущего $b$: если ослабить $i$-е ограничение на $\varepsilon$, оптимальное значение изменится примерно на $y_i^\ast\varepsilon$ (пока не изменился набор активных ограничений — раздел 10 конспекта, рис. 09).
