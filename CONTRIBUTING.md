# Как сдавать домашние задания

С ДЗ 3 задания сдаются через **GitHub Classroom**: у каждого студента свой **приватный** репозиторий, который видите только вы и преподаватель. Чужие решения никто не видит, и ваше никто не видит.

ДЗ 1 и 2 сдавались pull request'ом в публичный репозиторий курса. Эти работы остаются публичными, порядок их сдачи — в [конце страницы](#дз-1-и-2-pull-request-в-публичный-репозиторий).

## ДЗ 3 и дальше: GitHub Classroom

### Один раз в начале семестра

1. Заведите аккаунт на [github.com](https://github.com), если его ещё нет. Преподаватель сопоставляет вашу работу с ведомостью по логину GitHub, поэтому сообщите ему логин, если ещё не делали этого.
2. Для каждого задания преподаватель присылает **ссылку-приглашение** в чат курса. Ссылка работает только для этого задания.

### На каждое домашнее задание

1. Перейдите по ссылке-приглашению, при первом запуске разрешите GitHub Classroom доступ к вашему аккаунту и нажмите **Accept this assignment**. Если Classroom покажет список группы, выберите в нём свою фамилию.
2. Через минуту страница покажет ссылку на ваш новый репозиторий вида `numopt-hw03-<ваш-логин>`. Это приватная копия шаблона: в ней лежат ноутбук `hw03.ipynb`, `README.md` и файл `requirements.txt`.
3. Решите задание в ноутбуке `hw03.ipynb`. Один из способов:
   - **Локально.** Склонируйте репозиторий и откройте ноутбук (`uv sync`, затем `uv run jupyter lab`, или `pip install -r requirements.txt`).
   - **Google Colab.** В Colab выберите `File → Open notebook → GitHub`, разрешите доступ к приватным репозиториям и откройте ваш репозиторий. Сохранить обратно: `File → Save a copy in GitHub`.
   - **Через браузер без git.** На странице репозитория нажмите `Add file → Upload files`, перетащите заполненный `hw03.ipynb` и выберите `Commit directly to the main branch`. Файл должен называться так же, как исходный.
4. Перед отправкой выполните ноутбук целиком: `Kernel → Restart Kernel and Run All Cells`. В отправленном ноутбуке должны быть видны результаты выполнения.
5. Отправьте работу в ветку **`main`** вашего репозитория:

   ```bash
   git add hw03.ipynb
   git commit -m "hw03: решение"
   git push origin main
   ```

   Можно отправлять несколько раз: проверяется последняя версия, отправленная до срока.
6. Откройте вкладку **Actions** вашего репозитория. Проверка выполняет ноутбук с нуля и ищет оставшиеся заглушки (`# ваш код`, `raise NotImplementedError`, `Ответ: (ваш текст…)`). Зелёная отметка значит, что ноутбук выполняется без ошибок и заглушек не осталось. Она **не** значит, что решение верное: оценку ставит преподаватель. Красная отметка до срока — повод посмотреть журнал и поправить.

### Срок и опоздание

Срок — до начала занятия в день, указанный в [карточке задания](homeworks/hw03.md). Опозданием считается push в `main` после этого момента: время вашего последнего push GitHub показывает по кнопке **Activity** на главной странице репозитория. Если срок сорвался по уважительной причине, напишите преподавателю заранее.

### Оценка и вопросы

Оценка и комментарии придут в pull request **Feedback** в вашем репозитории (вкладка Pull requests), баллы по пунктам — в сводной ведомости курса. Этот pull request создаёт Classroom: **не закрывайте его и не вливайте**. По ответу можно писать прямо в его обсуждении.

### Правила приватности

- Репозиторий приватный: не делайте его публичным и не добавляйте в него других людей, кроме преподавателя.
- Задачи можно обсуждать, но код и текст решения пишутся самостоятельно. Не показывайте решение другим студентам и не выкладывайте его в публичные места.
- Не меняйте файлы, кроме `hw03.ipynb`, и не меняйте начальное число генератора в ячейках с данными: проверка и сравнение результатов идут по одним и тем же данным.

### Если не хотите использовать GitHub

Напишите преподавателю: решение обсудим индивидуально, например отправка ноутбука на почту.

## ДЗ 1 и 2: pull request в публичный репозиторий

Эти работы сдаются через fork и pull request. Решение в таком pull request видно всем, как и сам форк; для новых заданий это уже не используется.

1. Нажмите **Fork** в правом верхнем углу [репозитория курса](https://github.com/IlyaChichkanov/Numerical-Optimization) и склонируйте свой форк:

   ```bash
   git clone https://github.com/<ваш-логин>/Numerical-Optimization.git
   cd Numerical-Optimization
   git remote add upstream https://github.com/IlyaChichkanov/Numerical-Optimization.git
   ```

2. Обновите копию и создайте ветку под задание:

   ```bash
   git checkout main
   git fetch upstream
   git merge upstream/main
   git push origin main
   git checkout -b hw02-<фамилия>
   ```

3. Заполните ноутбук (`homeworks/hw02.ipynb`), выполните его целиком и положите в `submissions/hw02/<фамилия>.ipynb` (см. [`submissions/README.md`](submissions/README.md)):

   ```bash
   git add submissions/hw02/<фамилия>.ipynb
   git commit -m "hw02: <фамилия>"
   git push origin hw02-<фамилия>
   ```

4. На странице своего форка нажмите **Compare & pull request**. Base repository — `IlyaChichkanov/Numerical-Optimization`, base — `main`; head — ваш форк и ветка. Название PR — `hw02: <фамилия>`.
5. Если нужно что-то исправить, коммитьте в ту же ветку, PR обновится сам. Дедлайн — момент открытия PR, а не мержа.
