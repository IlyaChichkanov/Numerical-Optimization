# Сдачи домашних заданий

Здесь лежат работы по ДЗ 1 и 2, которые приходили pull request'ами. С ДЗ 3 работы сдаются в личных приватных репозиториях GitHub Classroom, эта папка для них не используется. Инструкция для студентов — в [`CONTRIBUTING.md`](../CONTRIBUTING.md).

Структура: один файл на студента на задание, `submissions/hwNN/<фамилия>.ipynb`. Не редактируйте чужие файлы и не переименовывайте свой между заданиями — так проверка идёт по одному и тому же пути для каждого студента весь семестр.

```
submissions/
  hw01/
    ivanov.ipynb
    petrova.ipynb
    ...
  hw02/
    ...
```

Оценка и комментарии по ДЗ 1 и 2 — в сводной ведомости курса; по ДЗ 3 и далее — в pull request «Feedback» личного репозитория.
