# Сдачи домашних заданий

**С ДЗ 3 новые работы сюда не принимаются:** каждый сдаёт в свой закрытый репозиторий `optimisation-misis-2026/numopt-<логин>` — см. [`CONTRIBUTING.md`](../CONTRIBUTING.md). Здесь остаются работы ДЗ 1–2 и первые две работы ДЗ 3, сданные pull request'ом.

Структура: один файл на студента на задание, `submissions/hwNN/<фамилия>.ipynb`. Не редактируйте чужие файлы и не переименовывайте свой между заданиями — так проверка идёт по одному и тому же пути для каждого студента весь семестр.

```
submissions/
  hw01/
    ivanov.ipynb
    petrova.ipynb
    ...
  hw02/
    ...
```

Оценка и комментарии к этим работам публикуются как комментарий в соответствующем pull request.
